# Моё сафари — универсальная тестовая версия

Отдельная копия версии 18, без вмешательства в личный дневник путешествия.

### Уже работает
- 199 карточек животных, каталог и поиск
- запись наблюдений по произвольным датам
- выбор парка (Тарангире, Серенгети, Нгоронгоро)
- подсчёт видов и встреч, прогресс «Большой пятёрки»
- формирование сторис 9:16, экспорт JSON
- отдельное локальное хранилище `universal-safari-companion-v1`
- отдельная база фотографий `universal-safari-photos`, отдельный service worker

### Ограничения бета-версии
- Пока только три парка Танзании; нет самостоятельного выбора страны
- Пока только одна поездка на устройстве, без аккаунта и синхронизации
- Частичная офлайн-поддержка: изображения, особенно загружаемые с iNaturalist, доступны офлайн после кэширования
- Права на фотографии и корректность атрибуции необходимо проверить перед коммерческим распространением
- Исходники исторической версии были доступны лишь как собранный JS-бандл; для дальнейшего масштабирования нужен нормальный проект со сборкой и тестами

### Безопасность данных
Версия расположена по другому URL и сохраняет данные отдельно. Оригинальное приложение и его ключ `arthur-safari-companion-v1` не меняются.
