# Моё сафари · Танзания 2026

Русский мобильный дневник наблюдений для поездки в Тарангире, Серенгети и Нгоронгоро.

**Открыть приложение:** https://shamilgalimullin-gif.github.io/arthur-tanzania-2026/

В приложении есть:

- каталог из 46 животных с фотографиями и подсказками;
- фильтры по трём национальным паркам;
- отметки встреч, количество, дата, заметка и своя фотография;
- прогресс «Большой пятёрки»;
- чек-лист вещей для сафари;
- сохранение данных на устройстве и резервная копия;
- офлайн-режим после первого открытия.

На iPhone откройте ссылку в Safari и выберите «Поделиться» → «На экран Домой».
